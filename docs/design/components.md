# Catálogo visual

## `@portfolio/ui`

- `action-link`: enlace de acción.
- `badge`: etiqueta con variantes `neutral`, `accent`, `success`, `warning`, `info`, `muted`.
- `button`: botón/enlace con variantes `primary`, `secondary`, `ghost`, `danger`, `outline` y tamaños `sm`, `md`, `lg`.
- `card`: contenedor editorial.
- `link-button`: enlace visualmente destacado.
- `section-title`: título de sección.
- `social-link`: enlace externo.
- `timeline` y `timeline-item`: línea temporal.
- Iconos base reutilizables.

## Importación recomendada

```astro
import Button from "@portfolio/ui/button";
import Card from "@portfolio/ui/card";
```
