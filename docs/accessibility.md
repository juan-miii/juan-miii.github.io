# Accesibilidad

Lista de verificación para WCAG 2.2 AA:

- Navegación completa con teclado.
- Foco visible en componentes y enlaces.
- Jerarquía semántica con un único `h1` por página.
- Contraste suficiente en tokens.
- Etiquetas accesibles y texto alternativo.
- `prefers-reduced-motion` respetado.
- Página 404 usable sin JavaScript.
- Componentes con estados `:focus-visible` y `:disabled`.
