# Política de seguridad

## Versiones soportadas

| Versión | Soportada |
|---------|-----------|
| `main`  | ✅        |

## Reportar una vulnerabilidad

Si crees que has encontrado una vulnerabilidad de seguridad en este proyecto, por favor **no abras un issue público**. Envía un reporte privado a través de [GitHub Security Advisories](https://github.com/juan-miii/juan-miii.github.io/security/advisories/new) o por correo electrónico al contacto indicado en [`security.txt`](./apps/web/public/.well-known/security.txt).

Incluye la mayor cantidad de detalles posible:

- Descripción de la vulnerabilidad y su impacto.
- Pasos para reproducirla.
- Versión del proyecto y entorno donde se reproduce.
- Posible mitigación o parche, si lo tienes.

## Qué esperar

- Recibirás una confirmación de recepción en un plazo razonable.
- Te mantendremos informado del estado de la investigación.
- Si la vulnerabilidad se confirma, se publicará un parche y, cuando corresponda, un aviso de seguridad (GitHub Advisory).

## Alcance

Este proyecto es un sitio estático generado con Astro y publicado en GitHub Pages. No incluye servidor propio, bases de datos ni integraciones de terceros que gestionen datos de usuario más allá de los enlaces de contacto públicos.

## Archivo security.txt

El sitio expone un archivo [`security.txt`](./apps/web/public/.well-known/security.txt) con el contacto y el idioma preferido para reportes de seguridad, conforme al estándar [RFC 9116](https://www.rfc-editor.org/rfc/rfc9116).
