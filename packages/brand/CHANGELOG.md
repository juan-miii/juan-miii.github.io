# @juan-miii/brand

## 1.0.0

### Major Changes

- Full repository transformation into a monorepo, with the portfolio brand and
  identity redefined. The package now ships the new design tokens, base styles,
  layout and component primitives. The internal Tailwind dependency has been
  removed.

## 0.1.0

### Minor Changes

- Initial public release of the shared visual identity package: design tokens,
  base styles (reset, shell, section rhythm, node labels, dark field, skip link),
  layout primitives, component primitives (buttons, prose), motion reveal helpers
  and loader CSS.
