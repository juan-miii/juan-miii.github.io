# @juan-miii/brand

Shared visual identity for Juan Miguel's portfolio monorepo: design tokens,
base CSS, layout, components, motion and loader. Consumed by `apps/web` and
reusable by the future Starlight blog.

The Astro base components live in `packages/ui`.

## Usage

```css
@import "@juan-miii/brand/styles/base.css";
@import "@juan-miii/brand/styles/tokens.css";
```

## Available exports

- `./styles/tokens.css`
- `./styles/base.css`
- `./styles/icons.css`
- `./styles/layout.css`
- `./styles/components.css`
- `./styles/motion.css`
- `./styles/loader.css`
