## Reportar problemas

Para errores, solicitudes de funcionalidad o preguntas generales, abre un issue en este repositorio usando las plantillas de `.github/ISSUE_TEMPLATE/`.

Para vulnerabilidades de seguridad, consulta [`SECURITY.md`](./SECURITY.md) y usa GitHub Security Advisories o el contacto de `security.txt`.

## Comunidad

Este es un portfolio personal mantenido por una sola persona. Las respuestas pueden no ser inmediatas, pero se revisan los issues y pull requests con regularidad.
